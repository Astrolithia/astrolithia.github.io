AOP 面向切面
AOP 之前 之后
前建议 连接点之前运行的建议 返回建议后 在连接点正常完成后运行的建议 在方法跑出一场退出时运行的建议 finally 后 无论连接点已何种方式退出都要运行
周围 环绕建议可以在方法调用前后 在方法调用前后执行自定义行为
建表 智能体日志表 taskId 关联具体的创作任务
日志实体类 Builder 注解方便后续在 AOP 切面中通过链式调用构建日志对象
调用总耗时 各智能体耗时

@Async 它的实现是方法交给线程池执行，调用方不等待方法执行完成

AOP 方案的核心在于 业务代码只需要加一个注解 日志记录逻辑就自动完成了 这个注解只需要一个属性 智能体名称
有了注解 然后实现切面本身
切面核心逻辑是通过 @Around 环绕通知，在目标方法执行前记录开始时间、提取输入参数，执行后记录结束时间和输出结果，无论成功还是失败都通过 finally 异步保存日志 这样既不入侵业务代码，也不会因为日志写入失败而影响流程
启动类添加启动 AOP 代理
有了切面和启动类配置 要让每个智能体方法都能被切面拦截 一是给每个智能体方法加上 @AgentExecution 注解 二是把这些方法从 private 改为 public 阶段执行方法中调用智能体方法时不能直接用 this 而要通过 getProxy 拿到代理对象
