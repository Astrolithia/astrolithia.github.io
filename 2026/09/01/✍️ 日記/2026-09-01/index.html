Rust 包、Crates 与模块

随着项目的增长，应该通过将代码分解为多个模块和多个文件来组织代码。一个包（package）可以包含多个二进制 crate 项和一个可选的库 crate。
crate 是 Rust 编译器每次处理的最小代码单位。即使使用 rustc 而不是 cargo 来编译单个源代码文件，编译器也会把那个文件视为一个 crate。
crate 有两种形式：二进制 crate 和库 crate。
一个包会包含一个 Cargo.toml 文件。Cargo 实际上就是一个包，它包含了用于构建你代码的命令行工具的二进制 crate。
子模块：在除了 crate 根节点以外的任何文件中，可以定义子模块。比如可以在 src/garden.rs 中声明 mod vegetables;。编译器会在以父模块命名的目录中寻找子模块代码：

  • 内联，直接在 mod vegetables 后方不是一个分号而是一个大括号
  • 在文件 src/garden/vegetables.rs
  • 在文件 _src/garden/vegetables/mod.rs

模块树

路径

为了向 Rust 指示在模块树中从何处查找某个项，我们使用路径，就像在文件系统中使用路径一样。为了调用一个函数，我们需要知道它的路径。
路径有两种形式：

  • 绝对路径：以 crate 根（root）开头的完整路径；对于外部 crate 的代码，是以 crate 名开头的绝对路径，对于当前 crate 的代码，则以字面值 crate 开头
  • 相对路径：从当前模块开始，以 self、super 或当前模块中的某个标识符开头
    绝对路径和相对路径都后跟一个或多个由双冒号分割的标识符

在 Rust 中，所有项（函数、方法、结构体、枚举、模块和常量）默认对父模块都是私有的。如果希望创建一个如函数或结构体的私有项，可以将其放入一个模块。
可以使用 pub 关键字来创建公共项，使子模块的内部部分暴露给上级模块
模块公有不代表其内容也是公有的，如果想访问其他模块的内容，得在内容上也添加 pub 前缀

super开始的相对路径

可以通过在路径的开头使用 super，从父模块开始构建相对路径，而不是从当前模块或者 crate 根开始

如果在一个结构体定义的前面使用了 pub，这个结构体会变成公有的，但是这个结构体的字段还是私有的。可以根据情况决定每个字段是否公有。

与之相反，如果将枚举设为公有，则它的所有变体都将变为公有。只需在 enum 关键字前面加上 pub

如果枚举变体不是公有的，那么枚举会显得用处不大。而结构体在许多情况下即使字段不可公有也能正常使用，所以结构体字段遵循默认私有的通用原则，除非使用 pub 关键字

使用 use 关键字将路径引入作用域

可以使用 use 关键字创建捷径，然后在作用域中的任何地方使用这个更短的名字。

在作用域中增加 use 和路径类似于在文件系统中创建软链接。通过在 crate 根增加 use crate::front_of_house::hosting，现在 hosting 在作用域中就是有效的名称了
use 只能创建 use 所在的特定作用域内的捷径，比如如果将函数移动到别的子模块就无法编译

创建惯用的 use 路径

使用 use 引入结构体、枚举和其他项时，习惯是指定它们的完整路径。

使用 as 关键字提供新的名称

使用pub use重导出名称

使用 use 关键字，将某个名称导入当前作用域后，该名称对此作用域之外还是私有的。若要让作用域之外的代码能够像在当前作用域中一样使用该名称，可以将 pub 与 use 组合使用。这种技术被称为 重导出
