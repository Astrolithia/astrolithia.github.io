Docker 容器

容器是 Docker 的又一核心概念，简单来说，容器是独立运行的一个或一组应用，以及它们的运行态环境

前台运行：默认

前台运行时，容器会把输出的结果打印到宿主机上面。此时：

  • 终端被占用，无法执行其他命令
  • 按 Ctrl+C 会终止容器
  • 关闭终端容器，容器也会停止

后台运行：使用 -d 参数

使用 -d 参数后：

  • 容器在后台运行
  • 终端立即释放，可以继续执行其他命令
  • 输出不会直接显示（需要用 docker logs 查看）

然后用 docker ps 查看，发现容器根本不在运行，这是因为 容器的生命周期与主进程绑定
当运行时：

  1. 容器启动
  2. 没有指定命令，默认执行 /bin/bash
  3. 但没有交互式终端，bash 发现没有输入源
  4. Bash 立即退出
  5. 主进程退出，容器停止
