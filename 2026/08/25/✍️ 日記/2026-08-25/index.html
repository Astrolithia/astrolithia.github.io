RUN 执行命令

基本语法

RUN 在当前镜像层之上创建一个新层，执行指定的命令，并提交结果

RUN 的两种格式

  1. Shell 格式

特点：默认通过 /bin/sh -c 执行
优势：可以使用环境变量 管道 重定向等 Shell 特性
2. Exec 格式

特点：直接调用可执行文件，不经过 Shell
优势：避免 Shell 字符串解析问题，适用于参数中包含特殊字符的情况
注意：无法使用 $VAR 环境变量替换（除非显式调用 Shell）

RUN 最佳实践

组合命令：减少层数
每一个 RUN 指令都会新建一层镜像。为了减少镜像体积和层数，应使用 && 连接命令
清理缓存
在安装完软件后，立即清除缓存，可以显著减少镜像体积
**使用 set -e 和 pipefail **

高级技巧

BuildKit 支持在 RUN 指令中使用 --mount 挂载缓存，加速构建。
安全地使用 SSH 密钥或 Token，而不将其记录在镜像中。
BuildKit 支持使用 heredoc 语法编写多行脚本，无需行末反斜杠 \ 连接

COPY 复制文件

COPY 是在构建镜像时，将构建上下文中的文件或目录复制到容器内的指令 它是处理应用代码、配置文件最常用的方式

COPY 会保留源文件的元数据

  • 读、写、执行权限
  • 修改时间

大多数场景都应该使用 COPY 而不是 ADD，有两种场景用 ADD 更合适

  • 自动解压 tar 压缩包
  • 从 URL 下载公开远程文件

tmpfs 挂载会把数据放在内存中
适用于

  • 临时缓存
  • 会话数据
  • 不希望落盘的敏感中间文件
